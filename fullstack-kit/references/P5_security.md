# P5｜安全检查与人为审核

目标：从攻防角度复审交付物。

步骤：
1. 复审身份认证、会话管理、服务端权限、跨客户访问、密钥及凭证轮换。
2. 检查注入、XSS、CSRF、SSRF、路径穿越、依赖漏洞、文件上传限制、提示词注入。
3. 检查日志与备份是否包含个人信息；保留期限与查询授权是否合规。
4. 模拟外部消息/表格欺骗与机器人越权工具调用；越权必须被服务端阻断。
5. 汇总 BLOCKER/HIGH/MEDIUM/LOW：列文件路径、可复现过程与缓解措施。

交付：`05_security_review.md`（不能用“没有发现风险”代替实际审查）。

反例：仅让 AI 承诺不泄露客户数据，而数据库/API 并无权限隔离。

验收：发现的问题有明确状态；BLOCKER/HIGH 未关闭不得上线。
