# P6｜构建、发布、回滚

目标：获得可复现交付与可执行恢复方案。

步骤：
1. 锁定依赖与环境配置，区分本地/测试/生产，不在仓库中存真实密钥。
2. CI 建议：lint、单元测试、集成测试、安全检查、build；有失败不得发布。
3. 记录数据库迁移顺序、备份/恢复演练、feature flag 和回滚条件。
4. 利用 `run_check.py` 运行**目标项目已存在的 build 命令**，证据在 `.fullstack/evidence` 中。
5. 部署前执行权限/变更影响审核，真实发布需用户单独明确授权；本包不会自动上线。

交付：`06_deploy_plan.md`、`06_rollback.md`，真实 build 日志。

反例：build 成功不意味着迁移回滚、故障转移或客户权限是正确的。

验收：构建退出码为 0；回滚步骤可按文档操作；生产操作仍需人工批准。
