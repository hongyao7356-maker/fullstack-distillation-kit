# P2｜数据模型、迁移、权限

目标：数据可信、权限明确、迁移安全。

步骤：
1. 数据字典、实体关系、唯一键、时间戳/时区、金额/精度、数据保留策略。
2. 对外部表格标记来源、同步频率、校验规则、过期状态和权威来源。
3. 制作角色 × 对象 × 操作 × 作用域权限矩阵，默认拒绝。
4. 设计唯一约束、数据库迁移、备份、回滚方案及迁移后核对 SQL（先评审，不直接连生产库）。
5. 为跨租户访问、过期权限、无匹配对象、重复同步设计负面测试。

交付：`02_data_model.md`、`02_migrations.md`、`02_authz_matrix.md`。

反例：客户手机号或微信群名称不能天然等同于强身份认证。

验收：每个数据输出有来源与授权规则；所有删除/改写有恢复路径。
