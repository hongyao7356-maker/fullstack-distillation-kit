# P7｜监控、应急、长期维护

目标：验证系统故障时可发现、可定位、可恢复。

步骤：
1. 明确关键 SLI/SLO、错误预算及告警责任；预算数字须用户确定，不能伪造。
2. 设计日志字段、traceId、审计日志、PII 脱敏、隐私保留策略。
3. 标定队列积压、失败重试、授权拒绝、外部连接异常及人工接管的监控规则。
4. Runbook：判断条件、应急止血、回滚、客服通知、事故复盘与根因追踪。
5. 定义故障演练：模拟云表格不可用/重复消息/错误报价/服务重启等，标明演练结果。

交付：`07_monitoring.md`、`07_runbook.md`。

反例：有监控图表但没有值班责任人和响应动作，不构成可运营闭环。

验收：模拟故障有观测指标、动作、通知及恢复路径；真实上线由业务方最后批准。
